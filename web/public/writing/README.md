# Writing seed media

The PNG files in this directory are original illustrative seed images generated for the ENGLISHGO TOEIC Writing practice library on 2026-07-16. They are used only with the original prompts in `src/lib/services/writing.ts` and do not reproduce ETS or third-party test material.

When adding external images in the future, store the source URL, licence, attribution requirement, and approval status in the Writing prompt record before publishing it.
