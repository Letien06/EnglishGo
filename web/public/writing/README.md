# Writing seed media

The PNG files in this directory are original illustrative seed images generated for the ENGLISHGO TOEIC Writing practice library on 2026-07-16. They are used only with the original prompts in `src/lib/services/writing.ts` and do not reproduce ETS or third-party test material.

The second content expansion adds five original scenes — `retail-shelves.png`, `warehouse-scanner.png`, `hotel-reception.png`, `garden-maintenance.png`, and `construction-briefing.png` — for the additional Part 1 picture drills. Several drills may intentionally use the same scene with different required word pairs, so learners practise a structure repeatedly without needing to memorize one answer.

The `*-card-v1.webp` files are 640px thumbnails for the scrolling library; `*-practice-v1.webp` files are 1280px images for an individual exercise. They are generated from the PNG source files, which remain here as the editable originals. Keep the version suffix when replacing an image because these media files are cached for one year.

When adding external images in the future, store the source URL, licence, attribution requirement, and approval status in the Writing prompt record before publishing it.
